## Задача

30.09.2026 владелец подтвердил переработку канбана по предоставленному
`kanban.txt` — HTML-структуре образца Odoo. Файл используется только для
визуального анализа; его код и зависимости не переносятся в CRM. Нужен канбан
с самостоятельными flex-группами этапов, фоном доски под ними, компактной
адаптивной шириной, двухстрочной шапкой и плотными карточками без случайных
линий. Не менять данные, функции, DnD, маршруты, API и права.
