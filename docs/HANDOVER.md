30.09.2026. Область ограничена собственной геометрией и контрастом чаттера;
серверную логику, API и состав разрешённых действий не менять.

## Границы и проверки

Разрешены только «Лог примечания», история изменений и уже существующие
вложения. Не добавлять сообщения, активности, подписчиков, почту, упоминания
или форматированный редактор. Чужие CSS и JavaScript Odoo не подключать, не
копировать и не исполнять.

Проверки перед коммитом:

```bash
cd frontend && npx tsc -b && npm test && npm run build
```
