# Эстафета

## В работе: «Назначенный бухгалтер» в полной карточке лида

### Согласовано владельцем

Выпадающий список расположен сразу после тегов. Он содержит 10 заданных
владельцем имён, не зависит от учётных записей CRM; пустое значение показывается
как «Выбрать». Значение хранится отдельно от продавца. Старые лиды остаются
пустыми. Поле доступно тем же людям, что и обычные поля карточки. Быструю форму,
список лидов и канбан менять не нужно.

### Сделано и проверено

- Backend: nullable `accountant_name` в модели и API; принимаются только
  10 согласованных имён или `null`. Миграция
  `backend/alembic/versions/20261007_0900_lead_accountant.py` добавляет
  nullable-колонку без переноса данных. Этап закоммичен локально:
  `8fc929b`.
- Frontend: фиксированный список в
  `frontend/src/features/crm/lead-form/accountant-options.ts`, поле под тегами,
  сохранение и очистка через автосохранение. Пустой выбор отправляется как
  `null`. UI-этап ещё не закоммичен.
- Backend: полный `pytest` и Ruff прошли; тесты проверяют создание, изменение,
  сохранение, очистку, пустое старое значение и отклонение неизвестного имени.
  Alembic SQL для диапазона `e3f4a5b6c7d8:head` подтверждает nullable-столбец.
- Frontend: все 89 тестов, `npm run lint`, `npm run format:check` и
  `npm run build` прошли. Сценарный тест проверяет список вариантов, выбор,
  сохранение и очистку.
