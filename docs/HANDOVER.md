## Задача

30.09.2026 владелец подтвердил новый план: визуально приблизить интерфейс к
предоставленному тёмному экрану Odoo максимально точно. Цель — совпадение
геометрии, плотности и цветовых ролей оболочки и канбана при сохранении
текущих CRM-данных и всех функций. Не добавлять маршруты, разделы, активности,
аватары, счётчики или другие возможности, которых нет в CRM. Публичные assets
Odoo разрешены только для текстового визуального анализа: не скачивать,
не подключать, не исполнять и не копировать.

## План по шагам

- [x] Шаг 1 — роли фона применены к рабочей области, колонкам, карточкам и
  заголовкам канбана. Двойная линия под панелью управления убрана: её нижняя
  граница теперь единственная. Локальные проверки прошли, отдельный commit и
  push выполнены.
- [ ] Шаг 2 — выровнять панель управления: высоты, отступы, кнопку «Новый»,
  поиск, счётчик и переключатели вида. Проверить и отправить отдельный commit.
- [ ] Шаг 3 — уплотнить канбан: ширины колонок, заголовки, индикаторы этапов,
  карточки, теги, звёзды, меню и прокрутку. Поведение DnD не менять.
  Проверить и отправить отдельный commit.
- [ ] Шаг 4 — проверить общие роли на карточке лида, чаттере, списках,
  заявках, формах, диалогах и админке; исправить только визуальные расхождения.
  Проверить и отправить отдельный commit.
- [ ] Шаг 5 — пройти обе темы, широкий и узкий экран; после визуального
  подтверждения владельца обновить `STATUS.md` и очистить этот файл отдельным
  commit.

## Проверки

После каждого кодового шага:

```bash
cd frontend && npx tsc -b && npm test && npm run build
```

Перед каждым commit: `git fetch origin arena/01a0f081-crm`, проверка состава
изменений и `git diff --check`. После push дождаться успешных GitHub Actions.
