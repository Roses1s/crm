## Договорённости из чата

Публичные `manifest`, `web.assets_web_dark.min.css` и
`web.assets_web_dark.min.js` CRM на Odoo используются только для анализа.
Запрещено подключать, выполнять или копировать их код и стили в CRM Detroid.
Цель — написать собственные короткие стили и компоненты, оптимизированные под
текущую CRM. Не переделывать другие разделы без отдельного запроса владельца.

## Чем проверять

```bash
cd frontend && npx tsc -b && npm test && npm run build
```

Для первого блока проверки успешно пройдены: `npx tsc -b`, 12 Vitest-тестов и
`npm run build`. Сборочный CSS также содержит правила с нашими токенами
ширины чаттера и высоты рабочей области.

## Хвосты и грабли

- Минифицированный JavaScript не запускать: он рассчитан на чужие API,
  зависимости и авторизацию. Разрешено только текстовое чтение.
- Прямое скачивание в `/tmp` недоступно из песочницы из-за TLS-ошибки
  `SSL_ERROR_SYSCALL`. Внешние assets не сохранялись; безопасное текстовое
  чтение выполнено через просмотр публичной страницы. Не добавлять их в Git и
  не включать в Docker-образ.
- После аналитических этапов не менять внешний вид «по догадке»: сначала
  показать владельцу карту отличий и согласовать очередной небольшой блок.
