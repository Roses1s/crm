## Нет активной задачи

30.09.2026 завершено обновление цветовой системы всей CRM. Владелец проверил
результат в светлой и тёмной теме и подтвердил: «подтверждаю».

Интерфейс использует собственные семантические токены поверхностей, текста,
границ, статусов, навигации, focus, overlay и skeleton. Палитра покрывает вход,
оболочку, канбан, списки, формы, заявки, чаттер, админку, диалоги, выпадающие
меню, пустые результаты и все важные интерактивные состояния. Поведение,
маршруты, API, права и данные не менялись.

Последние функциональные коммиты:

- `7de206d feat(интерфейс): обновить базовую палитру CRM`;
- `b978dd4 feat(интерфейс): тематизировать рабочие разделы CRM`;
- `dd13bd3 feat(интерфейс): оформить вход и служебные состояния`.

Локально и в GitHub Actions прошли `npx tsc -b`, Vitest (15 тестов),
`npm run build`, а также backend-проверки (`ruff`, `mypy`, `pytest`, миграции).

Для выкладки используйте:

```bash
ssh crm /opt/crm/deploy.sh
```

Если сервер ещё не переключён на `arena/01a0f081-crm`, сначала один раз
выполните команду из [`deploy/02-deploy.md`](deploy/02-deploy.md).

Следующую задачу начинать только по отдельному запросу владельца и с новым
согласованным планом. Внешние assets Odoo по-прежнему разрешены исключительно
для текстового анализа: не скачивать в репозиторий, не подключать и не
исполнять.
