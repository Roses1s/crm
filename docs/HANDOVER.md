## Нет активной задачи

30.09.2026 завершена повторная визуальная сверка канбана Detroid с
предоставленным экраном Odoo при масштабе браузера 100%. Владелец проверил
предпросмотр и подтвердил результат. Публичные материалы Odoo использовались
только для текстового визуального анализа: их код и зависимости в CRM не
переносились.

Канбан получил геометрию образца: стандартная запись 300 px, компактная —
240 px, группа — запись с двумя внутренними полями по 8 px; на широком экране
группы уходят в горизонтальную прокрутку. Панель действий стала 56 px (общая
высота с навигацией — 96 px), а её кнопки — 32 px. Шапка этапа, прогресс и
счётчик собраны в два ряда; обычные карточки имеют внутренние поля 12×8 px.
Данные, API, права, маршруты, поиск, quick-create, меню этапа и DnD не
менялись.

Последние функциональные коммиты:

- `2e1326c feat(интерфейс): расширить группы канбана до эталона`;
- `4333ede feat(интерфейс): выровнять панель канбана с эталоном`;
- `c97421b feat(интерфейс): выровнять ритм этапов и карточек`.

Локально и в GitHub Actions прошли frontend-проверки (`tsc -b`, Vitest —
15 тестов, сборка) и backend-проверки (`ruff`, форматирование, `mypy`, pytest —
60 тестов, миграции). Изменения опубликованы в ветке `arena/01a0f081-crm`.

Продакшен в этой сессии не менялся. Для выкладки используйте:

```bash
ssh crm /opt/crm/deploy.sh
```

Если сервер ещё не переключён на `arena/01a0f081-crm`, сначала один раз
выполните команду из [`deploy/02-deploy.md`](deploy/02-deploy.md).

Следующую задачу начинать только по отдельному запросу владельца и с новым
согласованным планом.
