## Задача

30.09.2026 владелец прислал сравнение канбана Detroid с образцом Odoo и
попросил убрать вертикальные линии-разделители между этапами. Колонки должны
быть самостоятельными поверхностями с видимым тёмным фоном доски между ними,
без серых границ. Геометрия карточек, этапов, прокрутка и DnD должны сохраниться;
менять данные, маршруты, API и права нельзя.

## План

- [x] Шаг 1 — вертикальные границы этапов заменены ровными промежутками с
  поверхностью канбана; прокрутка, свёрнутые колонки и DnD сохранены.
- [x] Шаг 2 — локально прошли типы, Vitest, сборка и `git diff --check`;
  отдельный commit и push выполнены.
- [ ] Шаг 3 — после проверки владельцем обновить `STATUS.md` и очистить этот
