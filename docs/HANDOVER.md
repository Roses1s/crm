## Задача

Пересмотр ролей и личные доски: остаются «Администратор» и «Менеджер»,
у каждого менеджера своя воронка со своими этапами и только своими лидами;
админ может открыть доску любого сотрудника.

**Начато:** 29.09.2026 · **от коммита:** `03a9a22`

## План по шагам

- [x] Шаг 1 — две роли вместо трёх, русские названия, миграция и тесты
- [x] Шаг 2 — владелец у этапа, стандартный набор при первом входе
- [x] Шаг 3 — изоляция: менеджер видит только свои лиды/заявки/активности
- [ ] Шаг 4 — удаление непустого этапа с переносом карточек
- [ ] Шаг 5 — админ открывает доску сотрудника по фамилии

## Договорённости из чата

- Роли: только `admin` и `manager`; в интерфейсе — «Администратор», «Менеджер».
- Стандартные этапы менеджера: Новый · Перезвонить · Вышел на ЛПР ·
  Потенциальный клиент · Уехали, ждём заявку.
- Менеджер видит **только свои** лиды, чужих не видно даже поиском.
- Удаление непустого этапа: спросить, куда перенести карточки.
- Админ на чужой доске работает с полными правами (не только просмотр).
- Теги общие: создаёт админ, менеджер только назначает.
- Перевозчиков менеджер видит и может добавить, редактирует админ.
- В базе продакшена только одна учётная запись — админ владельца.

- Деплоить лучше после шага 3: до него изоляция досок неполная.
