# Эстафета: что делается прямо сейчас

> Страховка на случай, если сессия оборвётся. Чат новому участнику недоступен —
> доступен только репозиторий, поэтому всё важное живёт здесь.

---

## Задача

30.09.2026 владелец расширил визуальную задачу: привести цвета **всей CRM** к
единой собственной палитре по тёмному образцу Odoo. В область входят вход,
оболочка приложения, навигация, канбан, списки, карточки, формы, заявки,
чаттер, админка, диалоги, выпадающие меню, загрузка и пустые состояния.
Поведение, маршруты, API, права и бизнес-логику не менять.

Публичные manifest/CSS/JS Odoo разрешены только для текстового анализа ролей
цвета. Не скачивать их в репозиторий, не подключать и не исполнять. Тёмная тема
ориентируется на образец; светлая остаётся светлой, но использует те же
семантические роли и достаточный контраст.

## Первые файлы для аудита

- `frontend/src/index.css` — общие токены light/dark;
- `frontend/src/shared/ui/` — базовые визуальные примитивы;
- `frontend/src/shared/layout/`, `frontend/src/features/` — оболочка и все
  пользовательские экраны;
- `docs/ODOO_REFERENCE_ANALYSIS.md` — только карта наблюдений, без чужого кода.

## Проверки

После каждого кодового шага:

```bash
cd frontend && npx tsc -b && npm test && npm run build
```

Каждый шаг — отдельный commit, push и ожидание GitHub Actions. Если для точного
сравнения не хватает скриншота конкретного блока, попросить его у владельца,
а не подбирать вид «на глаз».
