## Задача: карточка лида «1 в 1» с образцом Odoo 17 (тёмная тема)

Владелец прислал скриншот карточки лида из своей Odoo 17 (сборка adktrans,
тёмная тема) и просит привести оформление, цвета и размеры нашей карточки лида
к этому образцу.

### Договорённости из чата

- **Только визуал.** Маршруты, права, API и бизнес-логику не трогаем.
- **Чего у нас нет — не добавляем.** Поля (Компания, Customer, КПП, Лимит,
  ОКВЭД, Область, Часовой пояс, Email/Phone, «Что возят» и т. д.), кнопки
  («Преобразовать в сделку», «Конвертировать в билет») и вкладки чаттера
  («Отправить сообщение», «Активность», «Подписаться») из образца НЕ добавляем.
- **Темы:** тёмную выравниваем точно под образец, светлую подгоняем в тех же
  цветовых ролях, чтобы не разъехалась.
- Публичные файлы Odoo — только для текстовой сверки значений цветов, их код и
  CSS не подключаем и не копируем.
- Предпросмотр владелец попросил показать в конце (не держать запущенным).

### План по шагам (каждый — отдельный коммит с прогоном проверок)

1. Цвета: фирменный фиолетовый Odoo `#714B67` (подтверждён их
   manifest.webmanifest) вместо `#6B3E66`; выверка тёмных поверхностей и акцента.
2. Верхняя лента карточки: панель управления, ряд действий и статусбар.
3. Лист формы: полоса заголовка, две колонки, ширина подписей, ритм полей,
   звёзды приоритета, теги, блок «Продавец».
4. Чаттер: аватары, кнопки, разделители дат, строки изменений.
5. Финал: проверки, документация, пуш, зелёные Actions, вопрос про деплой.

### Затронутые файлы (ожидаемо)

- `frontend/src/index.css` — цветовые токены тем.
- `frontend/src/shared/ui/odoo-form.tsx` — примитивы формы.
- `frontend/src/features/crm/LeadFormPage.tsx` — карточка лида.
- `frontend/src/shared/ui/chatter.tsx` — лента справа.
