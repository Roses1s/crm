## Задача

30.09.2026 владелец подтвердил развитие канбана. Требуется: применять к тегам
их собственные цвета; сделать звёзды приоритета как на образце и редактируемыми
на самой карточке; разрешить перетаскивание этапов мышью с сохранением порядка;
убрать быстрое добавление лида из этапов и действие «Закрывающий этап» из меню.

Сохранить обычное создание лида кнопкой «Новый», добавление нового этапа справа,
перетаскивание карточек, данные лидов, права, маршруты и остальную бизнес-логику.
Под «Закрывающим этапом» владелец подтвердил удаление переключателя
«Закрывающий этап / Открывающий этап» из меню этапа, а не удаление самих этапов.

## Проверки

После каждого frontend-шага:

```bash
cd frontend && npx tsc -b && npm test && npm run build
```

Для шага с сервером дополнительно:

```bash
cd backend && .venv/bin/ruff check . && .venv/bin/ruff format --check . \
  && .venv/bin/mypy app && .venv/bin/python -m pytest
```

Перед commit: `git fetch origin arena/01a0f081-crm`, проверка состава изменений
и `git diff --check`. После push дождаться успешных GitHub Actions.
