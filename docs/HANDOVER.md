## Договорённости из чата

Нужен не предел количества строк, а автоматическое увеличение высоты редактора
внутренней записи. При большом тексте прокручивается страница или правая лента,
но не само поле ввода.

## Чем проверять

```bash
cd frontend && npx tsc -b && npm test && npm run build
```

## Хвосты и грабли

- После сохранения пустое поле должно вернуться к исходной высоте.
- Измерение высоты доступно только в браузере; тесту требуется подставить
  `scrollHeight`, так как jsdom самостоятельно его не рассчитывает.
