## Задача

30.09.2026 владелец сравнил CRM Detroid с экраном Odoo при одинаковом масштабе
браузера 100% и попросил добиться максимально точного визуального совпадения.
Расхождение подтверждено скриншотами: у Detroid уже группы этапов, рабочая
область начинается выше, а ритм заголовка этапа и карточки отличается. Нужна
только визуальная настройка структуры, размеров, типографики и поверхностей.

Не менять лиды, названия и порядок этапов, API, права, маршруты, поиск,
быстрое создание, меню этапа или DnD. Состав и число карточек на образце Odoo
принадлежат другой базе и не являются данными для переноса. Публичные материалы
Odoo используются только для текстового визуального анализа: код и зависимости
в проект не копировать, не подключать и не сохранять.

  размер 32 px и единый горизонтальный ритм; доступные действия сохранены.
  Локальные проверки прошли; отдельный commit и push требуется выполнить.

## Проверки

После каждого кодового шага:

```bash
cd frontend && npx tsc -b && npm test && npm run build
```

Перед commit: `git fetch origin arena/01a0f081-crm`, проверка состава изменений
и `git diff --check`. После push дождаться успешных GitHub Actions.
