## Нет активной задачи

30.09.2026 завершена визуальная переработка канбана по предоставленному
`kanban.txt` — HTML-структуре образца Odoo. Владелец проверил предпросмотр и
подтвердил результат. Публичные материалы Odoo использовались только для
текстового визуального анализа: их код и зависимости в CRM не переносились.

Канбан получил адаптивные самостоятельные группы этапов, двухрядную шапку
этапа и плотные карточки без постоянных рамок. Данные, API, права, маршруты,
быстрое создание и DnD не менялись. Последние функциональные коммиты:

- `7172db1 feat(интерфейс): выровнять геометрию групп канбана`;
- `da2ca11 feat(интерфейс): собрать шапку этапа канбана`;
- `b9193a8 feat(интерфейс): уплотнить ритм карточек канбана`.

Локально и в GitHub Actions прошли frontend-проверки (`tsc -b`, Vitest —
15 тестов, сборка) и backend-проверки (`ruff`, форматирование, `mypy`, pytest —
60 тестов, миграции). Изменения опубликованы в ветке `arena/01a0f081-crm`.

Продакшен в этой сессии не менялся. Для выкладки используйте:

```bash
ssh crm /opt/crm/deploy.sh
```

Если сервер ещё не переключён на `arena/01a0f081-crm`, сначала один раз
выполните команду из [`deploy/02-deploy.md`](deploy/02-deploy.md).

Следующую задачу начинать только по отдельному запросу владельца и с новым
согласованным планом.
