## Что осталось

Согласованные шаги 6–10 завершены в ветке. Production оставляем без изменений;
выкатка и применение миграции возможны только вручную по отдельному решению
владельца. До этого не запускать `deploy.sh` и не применять миграцию на сервере.

Если перед будущей ручной выкаткой владелец отдельно решит обновить клон
`/opt/crm`, команда только синхронизирует файлы и не запускает приложение:

```bash
ssh crm "cd /opt/crm && git fetch origin arena/6d4bde73-crm && git checkout -B arena/6d4bde73-crm --track origin/arena/6d4bde73-crm && git log --oneline -1"
```
