## Нет активной задачи

30.09.2026 завершена визуальная сверка CRM с предоставленным тёмным образцом
Odoo. Владелец проверил результат в предпросмотре и подтвердил: «все хорошо
продолжаем».

Уточнены и проверены: единая графитовая шапка без разделительной линии, уровни
поверхностей рабочей области/колонок/карточек канбана, 44-пиксельная панель
управления, плотность колонок и карточек, поиск, режимы просмотра, а также
общие роли заявок, форм, чаттера, списков, лаунчера и адаптивных разделителей.
Поведение, маршруты, API, права и данные не менялись.

Последние функциональные коммиты:

- `5769961 fix(интерфейс): объединить шапку в тёмной теме`;
- `6b25027 feat(интерфейс): разделить поверхности канбана`;
- `d104d9c feat(интерфейс): уплотнить панель управления`;
- `ec2cd4b feat(интерфейс): уплотнить канбан`;
- `841f3b6 feat(интерфейс): выровнять общие поверхности`.

Локально и в GitHub Actions для `841f3b6` прошли `npx tsc -b`, Vitest
(15 тестов), `npm run build`, а также backend-проверки (`ruff`, `mypy`,
`pytest`, миграции).

Для выкладки используйте:

```bash
ssh crm /opt/crm/deploy.sh
```

Если сервер ещё не переключён на `arena/01a0f081-crm`, сначала один раз
выполните команду из [`deploy/02-deploy.md`](deploy/02-deploy.md).

Следующую задачу начинать только по отдельному запросу владельца и с новым
согласованным планом. Внешние assets Odoo по-прежнему разрешены исключительно
для текстового анализа: не скачивать в репозиторий, не подключать и не
исполнять.
