### Как быстро поднять предпросмотр карточки (dev, SQLite, без Docker)

Скрипт засева лежит вне репозитория (в `/tmp`), пересоздать при необходимости.
Бэкенд на SQLite (кеш падает на in-memory, лимитер выключен), фронтенд —
`npm run dev` (проксирует `/api` на бэкенд). Вход демо-админом
`admin@example.com` / `Preview123`, карточка — `/crm/leads/1`.

Для выкладки на сервер:

```bash
ssh crm /opt/crm/deploy.sh
```

Следующую задачу начинать только по отдельному запросу владельца и с новым
согласованным планом.
