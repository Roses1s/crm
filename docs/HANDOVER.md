### Как быстро поднять предпросмотр карточки (dev, SQLite, без Docker)

Скрипт засева демо-лида лежит вне репозитория (в `/tmp/seed_preview.py`),
пересоздать при необходимости. Бэкенд на SQLite (кеш падает на in-memory,
лимитер выключен), фронтенд — `npm run dev` (проксирует `/api` на бэкенд).
Вход демо-админом `admin@example.com` / `Preview123`, карточка — `/crm/leads/1`.

Для выкладки на сервер (клон уже на ветке `arena/01a0f1e0-crm`):

```bash
ssh crm /opt/crm/deploy.sh
```

Следующую задачу начинать только по отдельному запросу владельца и с новым
согласованным планом.
