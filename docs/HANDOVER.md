## Нет активной задачи

30.09.2026 завершено обновление канбана. Владелец проверил предпросмотр и
подтвердил результат: «подтверждаю».

Реализованы собственные цвета тегов на карточках, интерактивные звёзды
приоритета, горизонтальное перетаскивание этапов с сохранением порядка, удаление
быстрого добавления лидов внутри этапов и пункта «Закрывающий этап» из меню.
Верхняя кнопка «Новый», добавление этапа справа, переименование, цвета, удаление
этапов и перенос карточек сохранены.

Последние функциональные коммиты:

- `165339b feat(канбан): добавить цвета тегов и смену приоритета`;
- `204c5a3 feat(канбан): убрать быстрое добавление из этапов`;
- `02d3000 feat(канбан): сохранять порядок этапов`.

Локально и в GitHub Actions для `02d3000` прошли frontend-проверки
(`npx tsc -b`, Vitest — 19 тестов, `npm run build`) и backend-проверки
(`ruff`, форматирование, `mypy`, pytest — 64 теста, миграции).

Для выкладки используйте:

```bash
ssh crm /opt/crm/deploy.sh
```

Следующую задачу начинать только по отдельному запросу владельца и с новым
согласованным планом.
