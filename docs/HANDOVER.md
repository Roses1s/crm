## Договорённости

- **Повторную production-выкладку без отдельного решения владельца не делать.**
- **Чистку кеша Docker не автоматизируем** (решение от 03.10.2026): каждая
  сборка оставляет 1,5–2 ГБ, поэтому в конце сессии с выкаткой агент напоминает
  о ней словами. Команда: `ssh crm "docker builder prune -f"`, затем
  `ssh crm "df -h / | tail -1"`.
- **Не применять и не удалять stash `pre-deploy-preserve-local-audit-changes`**
  на сервере: в нём прежние изменения аудита, не относящиеся к текущим задачам.
- Экспорт лидов в Excel/CSV, дашборд по активностям, мониторинг в Telegram и
  выгрузка бэкапов за пределы сервера — **не делать**, владелец отказался.

## Чем проверять

```bash
cd backend && .venv/bin/ruff check . && .venv/bin/ruff format --check . \
  && .venv/bin/mypy app && .venv/bin/python -m pytest
cd ../frontend && npm run lint && npm run format:check && npx tsc -b \
  && npm test && npm run build
cd .. && python scripts/snapshot.py
```

`alembic check` отдельно и только с SQLite (иначе лезет в PostgreSQL и падает
на DNS):

```bash
cd backend && rm -f /tmp/checks.db \
  && DATABASE_URL=sqlite+aiosqlite:////tmp/checks.db .venv/bin/alembic upgrade head \
  && DATABASE_URL=sqlite+aiosqlite:////tmp/checks.db .venv/bin/alembic check
```

Конфиг nginx локально проверить нечем — перед деплоем:
`ssh crm "cd /opt/crm && docker compose exec nginx nginx -t"`.
