## Задача

Сделать пропорции карточки лида и правого чаттера похожими на Odoo CRM 17 на
мониторе владельца 1920×1080 при масштабе браузера 100%.

**Начато:** 30.09.2026 · **от коммита:** `60553d9`

## Договорённости из чата

Владелец прислал полный снимок Odoo CRM 17 при разрешении 1920×1080 и масштабе
100%. На нём чаттер занимает около 34,3% ширины рабочей области (примерно
660px), карточка — оставшиеся 65,7% (примерно 1260px). Меняем только пропорции
двух блоков, без полей карточки и без содержимого чаттера. На экранах меньше
`lg` чаттер по-прежнему становится под карточкой.

## Чем проверять

```bash
cd frontend && npx tsc -b && npm test && npm run build
```

## Хвосты и грабли

- Значение указано в процентах, а не жёстких пикселях: соотношение сохранится
  при изменении размера окна и масштаба браузера.
- Визуальная сверка выполняется владельцем в браузере после выкладки: в
  песочнице нет браузера для точного сравнения с Odoo.
